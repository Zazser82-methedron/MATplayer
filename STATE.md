## Done
- Все 21 задача плана реализованы через subagent-driven-development (имплементер +
  ревью спеки + ревью качества на каждую), смержены в `master`, задеплоены.
- Live: https://zazser82-methedron.github.io/MATplayer/ (репо `Zazser82-methedron/MATplayer`,
  публичный, деплой через `.github/workflows/deploy.yml` на пуш в `master`).
- Пост-деплой хотфикс-раунд (пользователь увидел «сырой» сайт): не было глобального
  CSS → `#matplayer-root`/canvas схлопывались в маленький бокс (добавлен `src/index.css`,
  импортирован в `main.jsx`); аудио 404 из-за абсолютного пути без учёта Vite `base`
  (заменено на `import.meta.env.BASE_URL`); частицы рендерились в сотни px (формула
  `uPointSize * 300/-z` не учитывала реальную дистанцию камеры) — сцена была сплошным
  пятном, поправлено (`uPointSize: 0.2` + клэмп `min(..., 24.0)` в шейдере).
- Библиотека/поиск/полноценное переключение треков (по прямому запросу пользователя
  «допили интерфейс — песни, поиск, библиотеку, всё как в плеере»): раньше на артиста
  был захардкожен ровно один трек и не было способа выбрать конкретную песню. Теперь
  `src/data/index.js` собирает всех артистов/треки/тексты через `import.meta.glob`
  (не нужно трогать код при добавлении контента), `src/ui/Library.jsx` — модалка со
  списком и поиском (по названию/артисту/настроению), `PlayerControls` показывает
  название трека и умеет prev/next-track с авто-переходом на следующий трек по
  окончании (было `loop`). Попутно найден и исправлен смежный баг: смена `src` у уже
  смонтированного `<audio>` сама по себе не запускала воспроизведение — нужен явный
  `.load()+.play()`.
- 133 теста зелёных (`npm test`), прод-сборка чистая (`npm run build`), полный сценарий
  (открыть библиотеку → искать → выбрать трек → prev/next) проверен вживую на
  задеплоенном сайте через Playwright, не только по тестам.
- Контент: ЗМП/Cupsize — 3 полностью размеченных трека (Knives/ЗПППП/Flowers) + все
  26 текстов с таймингом (мигрировано из `cupsize-v2-story/karaoke.js`); 2 placeholder-
  артиста с контрастным настроением (по 1 треку, без реального аудио — осознанный
  пробел).
- Worktree `.worktrees/implementation` смержен и удалён, ветка `implementation` удалена.
